Adding a new roadmap

  1. Create a branch for it in the roadmaps repository, copied from dba-career-ladder, and change its content.
  2. In its public/firebase-config.js, give it a new ROADMAP.id, title and tagline.
  3. Create a Firebase Hosting site for it: firebase hosting:sites:create roadmaps-2b061-<id>, and set that site name in its firebase.json.
  4. Deploy it with firebase deploy --only hosting, then open it once while signed in as the teacher. It appears here and in every student’s list.
