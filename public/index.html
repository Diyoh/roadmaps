Adding a new roadmap

  1. Create a branch for it in the roadmaps repository, copied from dba-career-ladder, and change its content. Run node tools/export-outline.cjs on that branch after changing its levels.
  2. In that branch’s public/firebase-config.js, give it a new ROADMAP.id, title and tagline.
  3. On Master, add it to HUB.roadmaps in public/firebase-config.js with its branch and path.
  4. Run npm run deploy on Master. It publishes the hub and every roadmap together, and the new roadmap appears here and in every student’s list.
